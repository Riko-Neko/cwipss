# Three-Stage Compression Benchmark

This benchmark enforces one scientific data path:

```text
single-channel absolute CWT (period x time)
  -> frozen activity algorithm (time)
  -> native C++ PELT (time windows)
  -> boundary-only minimum-duration gate
  -> independent period-profile algorithm (period)
```

## Hard Boundaries

Stage 1 returns only a 1D activity axis and a diagnostic score map. Its internal
mask or compatibility window list cannot define stage-2 windows.

Stage 2 always calls the native C++ PELT implementation. Threshold windows and
Python PELT fallbacks are rejected. The configurable
`stage3_min_window_records` gate may only remove complete PELT windows; it never
changes their indices.

Stage 3 receives PELT indices and the original unmasked absolute CWT map. It
does not receive CPRO's score map, ridge mask, active mask, or window list.
Stage-3 calibration is independent:

```text
C(p,t) = P(p,t) / (sigma^2 * wavelet_gain(p))
tau_profile = max(profile_threshold_snr,
                  quantile(C, profile_texture_quantile))
Z(p,t) = C(p,t) / tau_profile
```

## Historical Pre-v2 Stage 1

The activity rank screened 366 strict single-channel `O(P*T)` candidates and
then ran 100 configured weak-signal groups on two independent CE4 files. Every
positive and negative window metric used native PELT.

The selected historical activity candidate was `sm_cpro_w769`, equivalent to
the pre-v2 CPRO with `window_support_records=769`. It uses first-difference MAD noise
calibration and emits calibrated-power activity. It performs no gap filling,
short-run deletion, or window generation before PELT.

Finalist evidence:

| Observation | Group recall | PELT windows / 23 real channels | Old 385-record baseline |
|---|---:|---:|---:|
| CE4 2021-12-05 | 89% | 7 | 53 |
| CE4 2019-08-30 | 86% | 6 | 66 |

## Stage-3 Duration Gate

The tested gates were 96, 192, and 384 records. On the first 20 injections,
PELT localized 17. The gates retained 17, 14, and 10 respectively, while all
three retained the same real negative window. The frozen test gate is therefore
96 records; larger values discarded true PELT windows without improving the
observed negative control.

## Frozen Stage 3

The rank evaluates 136 linear-time period-profile candidates using the original
metrics: positive acceptance, unconditional 5/10/20% period accuracy,
accepted-case 10% accuracy, truth-band coverage, harmonic confusion, real-window
false acceptance, and runtime.

The selected low-false-positive candidate is frozen as
`cprf_concentrated_ridge_c45`. It is parameter-identical to the ranked catalog
entry `pbsf_focus_concentration_c45`. Its reducer is the occupied-time mean multiplied
by square-root occupancy, smoothed over three period bins. A candidate requires:

```text
peak strength >= 1.25 calibrated threshold units
contiguous half-prominence width >= 3 period bins
integrated band strength >= 2.0
band persistence >= 0.35
main-band energy concentration >= 0.45
```

Harmonic responses rank hypotheses but are not acceptance gates. Adding the
tested local-contrast gates changed no decision at concentration 0.45, so the
simpler concentration-only variant is retained.

Across the two full 90-channel low-frequency controls:

| Observation | Positive PELT windows | Accepted / 10%-accurate | Real PELT windows | False accepted |
|---|---:|---:|---:|---:|
| CE4 2021-12-05 | 118 | 103 (87.3%) | 10 | 0 |
| CE4 2019-08-30 | 111 | 96 (86.5%) | 18 | 0 |
| Combined | 229 | 199 (86.9%) | 28 | 0 |

Every accepted positive estimate was within 10% of truth. Mean accepted period
error was 1.739%. These are real no-injection controls, not human-labeled
astrophysical false positives, so `0/28` is evidence for this dataset and not a
universal false-positive probability.

## Full-Band CPRF Stress Test

The stress test reconstructs the exact 1,051 and 3,253 historical no-injection
window indices generated by legacy CPRO-w385 on the two CE4 observations. The
window generator uses its historical 10--200-record period domain only to
recover indices. CPRF receives independently calibrated, original unmasked CWT
over the same 10--1000-record profile domain used by the positive cases. This
preserves the current Stage-3 boundary and does not restore legacy masked-map
logic.

The positive corpus contains 216 deterministic, independent weak injections
per observation, equally split among sinusoidal, medium-duty pulsed, and
narrow-duty pulsed models. Historical CPRO-w769 plus native C++ PELT recovers
420/432 windows (97.22%), producing a 4,304:420 or 10.25:1 paired stress set.

| Algorithm | Conditional acceptance | End-to-end acceptance | Historical retention | Accepted 10%-period accuracy |
|---|---:|---:|---:|---:|
| Old `cprf_absolute_ridge_c35_r140` | 369/420 (87.86%) | 369/432 (85.42%) | 556/4304 (12.92%) | 100% |
| Frozen `cprf_concentrated_ridge_c45` | 341/420 (81.19%) | 341/432 (78.94%) | 224/4304 (5.20%) | 100% |

The frozen CPRF therefore reduces retained historical negatives by 59.7%
relative while losing 6.67 percentage points of conditional acceptance. The
paired negative decisions are 143 both accepted, 413 old-only, 81 new-only,
and 3,667 both rejected (`p=6.26e-55`, one-sided exact binomial test). The
historical retention rate is an adversarial Stage-3 stress metric, not a
production PELT false-positive rate.

## Commands

Stage-1 broad rank:

```bash
PYTHONPATH=src:tests/perf python tests/perf/run_single_map_rank.py \
  --output runs/single_map_activity_pelt_broad_screen \
  --algorithms all-single-map \
  --max-groups-per-family 1 \
  --negative-channels 3,48 \
  --pelt-threads 8
```

Stage-3 full rank:

```bash
PYTHONPATH=src:tests/perf python tests/perf/run_period_profile_rank.py \
  --output runs/period_profile_pelt_rank \
  --activity-algorithm sm_cpro_w769 \
  --candidate-period-max-records 1000 \
  --stage3-min-window-records 96 \
  --negative-channels 3,4,5,6,7,8,9,10
```

```bash
PYTHONPATH=src:tests/perf python tests/perf/run_cprf_stress.py \
  --output runs/cprf_stress_legacy_negative_positive10to1_v1
```

Every run stores input, injection-config, and CWT-config SHA-256 hashes, the
selected stage boundaries, algorithm maps, per-case CSV files, and rank tables.
