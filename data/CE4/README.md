# CE4 Sample Data

Local raw CE4 `.2C` samples for development and smoke testing.

The `.2C` files are intentionally ignored by git. Their paired `.2CL` labels are
kept next to them because the reader uses those labels for frequency and time
metadata.

Selected samples:

| File stem | Role |
| --- | --- |
| `CE4_GRAS_LFRS-TR_SCI_P_20200122073100_20200122140000_0083_B` | Tiny smoke-test file. |
| `CE4_GRAS_LFRS-TR_SCI_P_20190103162200_20190103174300_0001_B` | Short early-observation sample. |
| `CE4_GRAS_LFRS-TR_SCI_P_20190830160000_20190831040000_0056_B` | Main file used during initial wavelet exploration. |
| `CE4_GRAS_LFRS-TR_SCI_P_20211205160000_20211206040000_0211_B` | Larger later-observation sample. |
